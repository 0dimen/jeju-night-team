# 합성 평가 자료의 범위

결론: 모든 입력은 합성이며 답안은 지시서에서 도출한 AI 작성 후보이다. 사용자 승인이나 실제 도민 제보 정답이 아니다.

`build_datasets.py`에 먼저 명시한 기대값을 고정한 뒤 실행한다. 결과를 보고 답안을 맞춰 바꾸지 않는다. 의미가 애매한 사례는 `ambiguous: true`로 표시하고 정확도 분모에서 제외하여 별도 표에 남긴다. 개인정보 검사는 합성 패턴으로 수행한다.

- 입력 52건, 제보 36건, 설명 경계 16건, 전체 흐름 12건.
- 매 세 번째 사례는 보정용, 나머지는 평가용. 독립 문구지만 같은 주제·문장 구조를 공유하므로 일반화 성능 검증에는 별도의 실제 사용자 표본이 필요하다.
- 모델별 부분 실험은 같은 앞부분 사례로 비교하며 실제 표본 수를 반드시 표시한다. 작은 표본의 우열을 전체 정확도로 확대하지 않는다.
- 원본 형식·규칙 기준은 `docs/TEST_ORACLES.md`. 애매 사례와 후보 답안 수정 요청은 사람 판단 목록에 남긴다.
