어떤 길을 걸을까요?

빠른 길과 CCTV 인접 구간을 비교해 보세요. 밝기와 실제 작동 상태는 확인하지 않습니다.

공개 구간의 시설 경로 연구와 합성 대화 시연을 제공합니다. 현재 밝기·작동·안전을 보증하지 않습니다. 실제 집 주소는 입력하지 마세요.

어디로 걸어갈까요?

장소·날짜·시각을 확인하고 같은 목적지의 경로를 비교해요.

공개 데이터로 길 찾기

도로망에서 시설 인접 구간이 많은 후보를 자동으로 찾습니다. 현재 두 공개 구간만 지원하는 연구 시연입니다.

연구 설정·자료 선택

반경·가중치·우회 한도는 시험용 설정입니다. 실제 밝기나 안전 기준이 아닙니다. CCTV는 생활방범·교통단속·어린이보호·시설물관리 목적을 포함합니다.
