# 수희에게 부탁할 시험 문장 15개

## 부탁할 내용

**제주 밤길 서비스를 쓰는 사람처럼 자연스러운 문장 15개를 써 주세요.** 프로그램이 알아듣기 쉽게 고치지 않아도 됩니다. 각 문장 옆에 ‘무엇을 원했는지’를 한 줄로 적어 주세요. 모호한 표현은 하나의 정답을 억지로 정하지 말고 ‘먼저 물어봐야 할 것’을 적어 주세요.

실제 주소·현재 위치·전화번호·다른 사람의 개인정보는 쓰지 마세요. 공개 장소 이름이나 가상의 상황이면 됩니다. 실제 위험 상황을 만들거나 시설을 직접 조작할 필요는 없습니다.

## 이런 상황으로 하나씩 써 주세요

| 번호 | 상황 | 포함하면 좋은 내용 |
|---|---|---|
| 1 | 길을 비교하고 싶음 | 출발지·도착지·출발 시각 모두 |
| 2 | 목적지만 말함 | 출발지는 일부러 생략 |
| 3 | 시간 없이 길을 물음 | 출발지·도착지만 |
| 4 | 일상적인 시간으로 말함 | ‘오늘 밤’, ‘내일 새벽’ 같은 표현 |
| 5 | 원하지 않는 조건도 말함 | ‘밝은 길 말고’, ‘돌아가도 괜찮아’ 등 |
| 6 | 가로등 고장을 알림 | 어느 시설에 무슨 문제가 있는지 |
| 7 | CCTV나 비상벨 문제를 알림 | 관찰한 사실만, 고장을 확신할 필요 없음 |
| 8 | 고장이 아니라고 말함 | 다른 불편과 함께 설명 |
| 9 | 시설 두 개의 문제가 섞임 | 한 문장에 여러 시설·문제 |
| 10 | 위치를 모르는 채 제보함 | 무엇을 추가로 물어봐야 할지 |
| 11 | 즉시 도움이 필요한 상황 | 가상의 위협·추적 상황 |
| 12 | 평범한 요청 중 긴급 상황을 말함 | 무엇을 먼저 처리해야 하는지 |
| 13 | 자료의 출처·오래된 정도를 물음 | 현재 상태까지 알 수 있는지 |
| 14 | 모호하게 불편을 말함 | ‘이상해’, ‘불편해’ 같은 표현 |
| 15 | 이 서비스가 하지 않는 일을 부탁함 | 예약·배달 등 |

전체 중 2~3개에는 평소 말투, 제주 표현, 짧은 문장이나 가벼운 오타를 섞어 주세요. 검색해서 예쁘게 다듬지 않아도 됩니다.

## 작성 형식과 예시

- **문장:** “동문시장까지 가려는데 어디로 걸어가?”
- **내가 원한 것:** 걸어갈 길을 알고 싶다.
- **먼저 물어볼 것:** 어디서 출발하는지, 언제 출발하는지.

- **문장:** “저기 비상벨 덮개가 깨진 것 같아요.”
- **내가 원한 것:** 시설 상태를 알려 담당자가 확인했으면 한다.
- **먼저 물어볼 것:** 위치와 정확히 무엇이 깨졌는지.

위 예시는 형식 설명용입니다. 문장을 그대로 복사하지 말고 본인 말투로 작성해 주세요. 답변에 거리·시설 개수 같은 숫자를 직접 계산할 필요는 없습니다.

## 받은 뒤 확인할 방법

문장과 의도를 먼저 보존한 뒤 프로그램에 입력합니다. 실제 응답을 옆에 붙이고, 수희가 ‘맞음 / 일부만 맞음 / 틀림 / 판단 어려움’과 이유를 확인합니다. 처음에 작성한 문장을 결과에 맞춰 바꾸지 않습니다. 수정한 프로그램은 같은 문장으로 재확인하고, 별도의 새 문장으로도 확인합니다.

이미 AI의 독립 작성 세션에서 합성 문장 15개로 예비 실행했습니다. 이 문장들은 수희가 직접 작성할 15개와 구분합니다. AI가 적은 의도는 사람이 승인한 정답이 아닙니다.
