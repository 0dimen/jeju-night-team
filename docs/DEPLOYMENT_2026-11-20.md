# 11월 20일 검토 수정 통합 배포

## 반영 범위

사용자의 ‘문제가 없다면 이제 배포에 반영’ 지시에 따라 화면·추천 기준·조회 흐름을 통합했습니다. 이번 명시적 배포 지시에 따라 제출 브랜치에 반영하며, 이전 아침 안내의 담당자 병합 대기를 이번 범위에 한해 해제합니다. 예비 태그는 유지합니다.

- 실제 제주데이터허브 월별 자료 표시·출처와 제보의 경로 미반영 안내
- 접속 직후 준비 확인·검색 중 안내·검색 처리 시간 계측
- CCTV/시간/조명 복수 선택, 선택 기준 우선 추천과 추천·제외 이유
- 시간대별 빈 항목 제거, 직접 두 지역 선택, 두 지역 각각의 상세 자료
- 시설 화면의 독립 구역 선택, 이전 구역 응답·실패 대체 방지

미확정 제보 반경·강도 후보는 운영 추천에 켜지 않았습니다. 시설 조회는 두 공개 구간 주변이고, 실제 게시 제보·관리자 승인·영구 저장 연결은 아직 없습니다. 이 한계 안내를 유지합니다.

## 배포 확인

기존 페이지를 열어 두었다면 새로고침합니다. 복수 기준 선택·추천 이유, 두 지역 상세 버튼, 시설 구역 선택 화면이 실제 주소에서 제공됩니다. Vercel 배포 상태도 성공입니다.

- 배포 브라우저 검사: 실제 장소 검색·접수·GPS 허용/거절/제주밖·긴급 안내·320/390/430px 화면·키 비노출·확인 화면 분리 통과.
- 배포의 두 지역 상세 검사: 390/768/1280px에서 대륜동·애월읍의 2019-06 기준 각 12개 월별 표시 값을 저장된 공개 자료와 대조, 뒤로 가기 통과.
- 실제 TMAP 공개 구간 요청: criteria=CCTV 단독, HTTP200, 서로 다른 후보1개, CCTV 인접30.21%, 미저장. 후보 한 개라는 추천 설명 확인. 실제 여러 후보 간 순위 검증은 아니며, 복수 후보 우선순위는 합성 검사로 별도 검증했습니다.
- 두 시설 구역 실제 API: 연동 반환 CCTV5/조명103지점, 서귀포 반환 CCTV9/조명92지점. 구간 주변 반환 목록 수이며 해당 읍면동 전체 시설 수나 현재 고장 수가 아닙니다.
- 추가 지출이 필요한 모델·호스팅 변경과 미확정 제보 점수 적용은 하지 않았습니다. 예비 submit-safe 태그를 유지했습니다. 사람의 실제 휴대폰·현장 통행·제출 확인은 완료로 처리하지 않았습니다.
