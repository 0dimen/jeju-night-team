# 제주밤길 팀 역할과 진행 계획

2026년 11월 18일 · 팀 공유용 요약

## 목표: 실제 자료로 길을 비교하는 시연 완성

**기능을 늘리기보다, 실제 자료를 연결하고 누구나 실행할 수 있는 제출본을 먼저 만듭니다.** 제주밤길은 걸어갈 길의 거리와 주변 시설을 비교하는 프로그램입니다. 안전을 보장하지 않습니다.

## 누가 무엇을 하나요?

| 담당 | 맡는 일 | 팀에 전달할 것 |
|---|---|---|
| **채원** | 시설 자료를 프로그램에 연결하고, 기능을 합쳐 제출할 컴퓨터에서 실행합니다. | 실행되는 프로그램과 제출 파일 |
| **혜수** | 일정과 진행 상황을 챙기고, 기획서·결과 보고서·사용 설명서를 정리합니다. | 제출 문서와 시연 순서 |
| **승유** | 자료를 써도 되는지, 자료가 길 비교에 적절한지 검토합니다. | 쓸 자료와 제외할 자료에 대한 의견 |
| **수희** | 도민·관광객이 쓸 만한 문장으로 시험하고, 제보 분류와 설명이 맞는지 확인합니다. | 시험 문장과 오류 목록 |

## 어떤 순서로 진행하나요?

1. **오늘:** 승유는 자료를 검토하고 채원은 연결·실행을 확인합니다. 혜수는 문서, 수희는 시험 문장을 준비합니다.
2. **내일 낮:** 길 비교·긴급 안내·고장 제보를 함께 시험합니다. 제보는 사람이 확인하고 게시한 뒤에만 길 비교에 반영합니다.
3. **내일 오후 6시 이후:** 새 기능 추가를 멈추고 오류를 고칩니다. 설명서대로 실행되는지 확인합니다.
4. **11월 20일 오전 8시:** 제출하고 접수 여부를 확인하는 목표입니다. 최종 마감은 오전 10시입니다.

## 먼저 끝낼 일과 나중에 할 일

**먼저:** 이용 가능한 실제 시설 자료 1종과 실제 보행 경로 2개를 연결해 거리·주변 시설·자료 기준일을 보여 줍니다. 제출할 컴퓨터에서 실행하고 설명서까지 확인합니다.

**시간이 남으면:** 애매한 말 되묻기, 가로등 자료 추가, 새로운 표현 이해를 차례로 검토합니다. 최소 시연이 끝나기 전에는 기능을 늘리지 않습니다.

## 현재 상황과 팀이 확인할 점

밤사이에는 가상 길과 시설로 기본 동작을 확인했습니다. 실제 CCTV 자료 479행은 받았지만, 사용 범위·실제 길 연결·제출 컴퓨터 실행은 미확인입니다. **정해 둔 규칙과 문장으로 처리하는 구성**이 기본이며 추가 AI 사용은 별도 검토합니다.

팀은 **교통단속용 CCTV 포함 여부와 오래되거나 없는 자료의 표시 방법**을 정해야 합니다. 개인정보와 미확인 성과는 제출물에 넣지 않습니다. 일이 막히면 혜수에게 이유와 필요한 도움을 알려 일정을 조정합니다.

기존 팀 역할 문서와 야간 결과를 쉽게 풀어 쓴 진행안입니다. 이 문서 작성으로 자료 사용이나 추가 기능을 승인한 것은 아닙니다.
