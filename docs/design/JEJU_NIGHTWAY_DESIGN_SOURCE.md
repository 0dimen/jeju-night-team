# 제주밤길 디자인 시스템 명세서

**JEJU NIGHTWAY · 개발용 v1.0**

기준 시안은 제주밤길 전체 UX 흐름도와 기능별 보드 6종입니다. UI를 구현할 때는 이 문서와 `tokens.css`의 값을 적용합니다. 보드에는 기존 화면을 참고 이미지로 수록했습니다. 이 버전에서 글자 대비를 위해 주요 버튼의 밝은 보라색을 낮추고, 작은 안내 라벨의 크기를 정리했습니다.

| 파일 | 개발에 사용하는 방법 |
|---|---|
| `tokens.css` | 팀 프로젝트의 앱 진입점에서 불러와 색상·글꼴·간격 변수를 컴포넌트에 적용 |
| `icons.svg` | 앱의 정적 자산 경로에 두고 SVG의 `<use>`로 기호를 불러옴 |
| `design-board.png` | 로고, 컬러, 글꼴, 컴포넌트와 기존 화면 적용을 한 장에서 확인 |

## 1. 브랜드와 홈 구성

- 공식 화면 이름은 **제주밤길**입니다. **JEJU NIGHTWAY**는 로고 아래 영문 보조 표기로 씁니다.
- 브랜드 마크는 기존의 달·별·오름 도형입니다. `icons.svg#jn-brand`를 보라색 라운드 사각 배경 위에 사용합니다. 홈 헤더 기준 바탕 30 × 30px, 모서리 9px, 마크 22px, 워드마크까지 간격 8px입니다.
- 홈 순서는 **로고 → 야간 배너 → 검색창 → 3+2 메뉴 → 지역 정보 카드 → 하단 탭**입니다. 첫 줄은 경로 비교·보행환경 제보·유동인구 분석, 둘째 줄은 지역 데이터 보기·시설 이슈입니다.
- 기능별 보드의 보라색 홈 타일은 어떤 메뉴로 진입하는지 보여주는 표시입니다. 실제 홈에서는 누르는 타일에 선택 윤곽을 표시하고, 화면 전환 후에는 현재 하단 탭을 강조합니다.
- 야간 풍경은 홈 배너에 배치합니다. 경로 결과와 제보 화면은 지도·아이콘·텍스트·지표로 구성합니다. 제보 입력은 위치·유형·상세 설명 중심입니다.

## 3. 글꼴과 수치

기본은 **Noto Sans KR**입니다. 시안 렌더링에 사용한 **Noto Sans CJK KR**과 시스템 글꼴을 대체 순서로 지정합니다. 글꼴을 직접 제공하는 앱에서는 웹폰트를 등록하고 `font-display: swap`을 적용합니다. 아래 px는 브라우저 기본 글자가 16px일 때의 참조값입니다.

| 쓰임 | 크기 / 줄높이 | 굵기 | 토큰 |
|---|---:|---:|---|
| 홈 배너 제목 | 30 / 39 | 700 | `--jn-type-hero` |
| 화면 안 큰 제목 | 26 / 34 | 700 | `--jn-type-display` |
| 상단 바 제목 | 17 / 24 | 700 | `--jn-type-title` |
| 버튼 | 15 / 22 | 700 | `--jn-type-button` |
| 본문·입력 | 14 / 21 | 400 | `--jn-type-body` |
| 보조 설명 | 13 / 20 | 400 | `--jn-type-support` |
| 출처·단위·배지 | 12 / 18 | 500 | `--jn-type-caption` |
| 하단 탭 이름 | 11 / 16 | 700 | `--jn-type-nav` |
| 비교 지표 | 21 / 28 | 700 | `--jn-type-metric` |

- 한글은 `word-break: keep-all`을 기본으로 적용하고, 긴 주소와 식별자는 `overflow-wrap: anywhere`를 허용합니다.
- 시간·거리·비율에는 단위를 붙입니다. 예시는 **18분 · 1.2 km · 45%**입니다. 수치 및 접수번호에는 `font-variant-numeric: tabular-nums`를 적용합니다.

## 4. 레이아웃과 모바일 반응형

| 항목 | 기준 |
|---|---|
| 시안·검증 폭 | 시안 390 × 844px. 320px·390px·430px에서 확인. 넓은 화면에서 일반 폼·카드 영역은 최대 480px |
| 좌우 여백 | 390px 기준 20px. 360px 이하에서 16px |
| 간격 체계 | 4px 단위. 필드·칩 사이 8px, 카드 사이 12px, 구역 사이 20~24px |
| 상단 영역 / 하단 탭 | 최소 52px / 최소 60px + 기기 하단 안전 여백 |
| 버튼 / 입력 / 텍스트 영역 | 최소 48px / 56px / 112px. 문구가 길면 높이를 늘림 |
| 모서리 | 입력 12px, 버튼 13px, 카드 14px, 지도 16px, 시트 24px |
| 터치 영역 | 버튼, 탭, 지도 도구, 아이콘 버튼은 최소 44 × 44px |

홈은 좁은 화면에서도 3+2 메뉴 순서를 유지하고, 라벨이 길면 두 줄로 표시합니다. 세로 콘텐츠는 스크롤됩니다. 키보드가 보일 때 입력·오류 문구에 접근할 수 있도록 스크롤 여유를 확보합니다. 하단 탭에는 `env(safe-area-inset-bottom)`을 적용할 수 있습니다. 시안의 시계·배터리·제스처 바는 기기 표시를 보여주는 요소입니다.

## 5. 아이콘

24 × 24 SVG 그리드에 선 두께 **1.75px**, 둥근 선 끝과 모서리를 사용합니다. 아이콘은 `currentColor`를 상속합니다. 문장 옆 아이콘 16px, 탭 20px, 기능 타일 24px를 기본값으로 둡니다.

| 쓰임 | 심벌 ID |
|---|---|
| 브랜드 | `jn-brand` |
| 하단 탭 홈 / 지도 / 제보 / 데이터 / 마이 | `jn-home` / `jn-map` / `jn-report` / `jn-chart` / `jn-user` |
| 경로·시설 이슈·검색 | `jn-route` / `jn-bell` / `jn-search` |
| 위치 핀·현재 위치·지도 레이어 | `jn-pin` / `jn-target` / `jn-layers` |
| CCTV·가로등·보행로 | `jn-camera` / `jn-lamp` / `jn-walk` |
| 시간·안내·확인·목록·새로고침 | `jn-clock` / `jn-info` / `jn-check` / `jn-list` / `jn-refresh` |
| 뒤로·상세 진입·다음·전송 | `jn-back` / `jn-chev` / `jn-right` / `jn-send` |

아이콘과 같은 뜻의 라벨이 보이면 SVG에는 `aria-hidden="true"`를 사용합니다. 아이콘만 있는 버튼은 버튼 자체에 기능 이름을 붙입니다. 예시의 파일 경로는 앱 정적 자산 경로에 맞춰 조정합니다.

```html
<button type="button" class="icon-button" aria-label="현재 위치 확인">
  <svg aria-hidden="true" width="20" height="20" focusable="false">
    <use href="/assets/icons.svg#jn-target"></use>
  </svg>
</button>
```

## 7. 지도·통계 화면

- **경로 A·B**는 각각 보라 실선과 청록 점선을 사용합니다. 어두운 지도에서 본선 5px, 외곽선 9px를 시작값으로 두고 B는 `7 6` 점선을 사용합니다. 지도·카드·범례가 같은 A/B 이름을 사용합니다.
- **GPS**는 위치 핀과 정확도 원을 사용합니다. 권한 거부나 위치 수신 실패 시 지도에서 문제 지점을 직접 찍을 수 있습니다.
- **시설 지도**에는 레이어, 기준이 되는 범위, 지도 없이도 읽을 수 있는 시설 목록을 둡니다.
- **CCTV 인접 구간**은 설치 위치 주변 50m와 경로가 겹친 정도입니다. 상세에 산정 기준, 출처, 기준일을 표시합니다. 위치 정보와 현재 작동·촬영 여부는 별도 항목입니다.
- **지역 활동 정보**의 기본 화면은 기존 시안에 맞춰 월별 방문 규모를 보여줍니다. 기준 월·공간 단위·출처를 함께 배치합니다. 시간대별 원본 연결 전에는 해당 옵션을 ‘자료 없음’으로 표시합니다.
- **제보 반영 전후 비교**에서 실제로 바뀐 항목을 강조합니다. 예를 들어 가로등 상태가 새로 게시됐을 때 CCTV 인접 비율이 그대로라면 유지된 값으로 표시합니다.
- 시연용 지도와 수치에는 ‘예시 지도’와 ‘예시’ 라벨을 사용합니다.

## 9. 개발 완료 확인

- [ ] 320px에서도 한글 제목과 버튼이 잘리지 않고 좌우 스크롤 없이 읽힌다.
- [ ] 키보드로 이동하면 포커스가 보이고 읽기 도구에서 아이콘 버튼 이름이 들린다.
- [ ] 지도와 카드의 A/B가 일치하고 색 외에도 선택 표시가 있다.
- [ ] GPS를 거부해도 제보 위치를 입력할 수 있다.
