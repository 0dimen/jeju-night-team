# 혜수 사용자 시험 계획: 시연과 기획서가 화면과 맞는지

2026년 11월 20일 08:00 시작 · 약 55분 · 주소 https://jeju-night-team.vercel.app/app

## 결론

**발표에서 보여 줄 순서를 실제 화면으로 리허설하고, 기획서에 쓴 말이 화면과 맞는지 하나씩 확인합니다.** 결과로 시연 시나리오 확정본, 기획서 수용 기준 체크표, 캡처 목록이 나옵니다.

- **소요 시간:** 약 55분 (시연 구간 고르기 10분, 리허설 15분, 문구 확인 15분, 수용 기준 표 10분, 캡처 5분)
- **준비물:** 노트북(크롬 권장), 휴대폰 1대, 초시계, 기획서 v3, 제출 체크리스트
- 수희는 실제 사용자 체감을 따로 시험합니다. 이 문서는 시연·문서 일치만 다룹니다.

## 시작 전 규칙

1. **실제 집 주소, 실제 전화번호를 넣지 않습니다.** 공개 장소와 가짜 번호 `010-0000-0000`만 씁니다.
2. **112나 119에 실제로 전화하지 않습니다.**
3. 이상한 점이 있으면 **화면을 캡처**하고 **"어느 화면에서 무엇을 눌렀는지"**를 메모합니다.
4. 결과 칸에는 ✅(기대대로) / ⚠️(되지만 고칠 점 있음) / ❌(안 됨) 중 하나를 적습니다.

## 이미 알려진 문제 (발표·문서에서 피하거나 밝힐 것)

- **제주시청 → 탑동광장은 비교 기준을 바꿔도 추천이 바뀌지 않습니다.** 기획서 대표 시나리오 구간이지만 시연에는 기준에 따라 추천이 바뀌는 구간을 쓰는 편이 안전합니다(아래 1~3번).
- **데이터 탭에 "과거 집계 자료 · 예시", "지역별 방문 통계 · 예시"가 남아 있습니다.** 유동인구·지역 비교는 이제 실제 제주데이터허브 자료입니다. 발표 전에 채원이 고치지 못하면 말로 바로잡습니다.
- **제보 → 검토 → 재분석은 화면 예시뿐입니다.** "마이"의 "시설 상태가 갱신됐어요" 화면은 예시입니다. 기획서에는 "구현 예정" 또는 "예시 화면"으로 씁니다.
- **다른 말로 쓴 위험 상황은 112 안내가 안 나오는 경우가 많습니다.** 발표에서 "모든 긴급 상황을 인식한다"고 말하지 않습니다.
- 사진 첨부, 유사 제보 확인, 출발·도착 교환 버튼은 없습니다.

## 시험 표

### A. 시연 구간 고르기 (노트북, 약 10분)

아래 **지도** 탭에서 출발지·목적지를 검색해 고르고, 출발 시각은 오늘 `22:00`으로 둡니다. 비교 기준 네 가지(**CCTV 인접 구간 / 이동 시간 / 조명 인접 구간 / CCTV·조명 함께**)를 바꿔 가며 **두 경로 비교하기**를 누르고, "추천" 표시가 붙은 경로 글자(A·B·C)를 적습니다.

| 번호 | 구간 | 기대 결과 | 기준별 추천 (CCTV / 시간 / 조명 / 함께) | 결과 | 메모 |
|---|---|---|---|---|---|
| 1 | `제주목관아` → `동문시장` | 기준마다 추천이 다름 (새벽 확인) | | | 시연 1순위 후보 |
| 2 | `동문시장` → `탑동광장` | 일부 기준에서 추천이 바뀜 | | | |
| 3 | `제주시청` → `탑동광장` | 모두 같은 경로 추천 (알려진 문제) | | | 시연에서 쓸지 결정 |

**결정:** 시연에 쓸 구간 = ______ (기준에 따라 추천이 바뀌고, 검색 결과에서 장소를 찾기 쉬운 구간을 고릅니다.)

## 결과 보내는 방법

**채원에게 09:00까지** 아래 양식으로 보냅니다.

```
[혜수 시연·문서 시험 결과]
- 시연 구간: (예: 제주목관아 → 동문시장)
- 시연 총 시간: __분 __초 (가장 오래 걸린 단계: )
- ❌ 목록: 번호 · 한 줄 설명 · 캡처 파일 이름
- 화면 문구 중 기획서와 다른 것:
- 수용 기준 9개 판정: 통과 __ / 일부 __ / 미구현 __
- 캡처 완료 수: __ / 11
```

## 기획서·시나리오에 쓸 수 있는 관찰 포인트

- **기획서 대표 시나리오 구간을 바꿀지:** 기획서는 제주시청 → 탑동광장이지만, 기준에 따라 추천이 바뀌는 구간이 "근거를 보여 주는 비교"를 더 잘 보여 줍니다.
- **"미구현"을 숨기지 않고 쓰는 방법:** 검증·재분석은 "시범 운영 단계에서는 화면 예시로 흐름을 보여 주고, 담당 검토 기능을 다음 단계에 연결"처럼 씁니다.
- **실제 자료 강조:** CCTV 937곳, 가로등·보안등 약 9만 곳, 제주데이터허브 유동인구 2017~2021년 월별 자료를 실제로 연결했습니다.
- **AI 사용 명시:** 서비스 실행 중에는 외부 언어모델을 쓰지 않고 규칙과 문장 틀로 설명합니다. 거리·시간·시설 수는 계산으로만 만듭니다.
- 시연 중 기다리는 시간(경로 비교 약 2~5초)에 할 설명 문장
