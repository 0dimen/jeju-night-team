# VWorld 배경지도 연결

## 결론

VWorld 키를 서버 환경변수로 읽어 공개 경로와 시설 위치를 배경지도에 표시합니다. 키 값은 HTML·JavaScript·브라우저 요청에 넣지 않습니다. 현재 두 공개 구간의 경로 계산은 그대로 유지합니다. 지도 연결이 보행 길찾기 API나 현장 검증을 대신하지 않습니다.

## 사용법

실행 서버에 `VWORLD_API_KEY`를 설정하고 기존 FastAPI 서버를 실행합니다. 로컬 `.env` 파일을 사용하는 경우 Git에 올리지 말고 서버 시작 전에 불러옵니다. Vercel에서는 프로젝트 환경변수에 설정한 뒤 다시 배포합니다. 발급 조건상 도메인이 필요하면 `VWORLD_DOMAIN`에 실제 등록한 서비스 주소를 설정합니다. 임의 도메인을 추측해서 넣지는 않습니다.

웹앱 `/app` → 지도 → 공개 구간 경로 계산 → **‘VWorld 배경지도·시설 위치 불러오기’**를 누릅니다. 사용자가 버튼을 누르기 전에는 타일을 요청하지 않습니다.

- 보라 실선: 최단 경로, 청록 점선: 시설 조건 우선 후보
- 주황 점: CCTV 공개 목록 위치, 파란 점: 조명 공개 목록 위치
- 출발·도착 표시와 경로 카드 선택을 지도 강조에 연결했습니다.
- 현재는 경로에 맞춰 범위를 고정한 지도입니다. 자유로운 지도 이동·주소 검색·GPS·로드뷰는 아직 없습니다.

배경지도 오류가 나면 실패를 안내하며 기존 좌표 도식과 거리·시설 비율을 유지합니다. 지도 일부가 누락된 경우도 안내합니다. 지도와 시설 점을 보았다는 이유로 보행 검토를 완료 처리하지 않습니다.

## 데이터와 키 처리

서버는 제주 범위의 제한된 줌 단계 타일만 중계합니다. 제공사 주소를 사용자 입력으로 받지 않습니다. VWorld에는 공개 지역의 타일 번호만 전달하며 대화 문장·집 주소는 보내지 않습니다. 브라우저는 같은 서비스 주소로만 요청합니다.

키 미설정은 503, 지원 범위 밖은 422, 제공사 인증·한도·비영상 응답은 일반 오류로 바꿉니다. 제공사 오류 본문과 키가 포함된 URL을 브라우저에 되돌리지 않습니다. 서버는 PNG만 받아 최대 크기를 제한하고, 중계 동시 요청 2개·분당 최대 120개로 호출 폭주를 제한합니다. 이는 제공사의 공식 무료 한도가 아니라 이 앱의 자체 제한입니다. 인증 오류·429 응답 시 60초 동안 추가 요청을 보류합니다. 타일을 저장하거나 대량 수집하지 않습니다. 표준 HTTP 라이브러리 로그에도 키 가림 필터를 적용했습니다. 운영 환경의 별도 프록시·플랫폼 로그에서도 키가 포함된 제공사 요청 URL을 기록하지 않아야 합니다.

시설 표시는 계산한 후보의 주변 약 100m 사각 범위에서만 가져옵니다. 시설별 최대 2,000개 표시 제한과 생략 여부를 알려 줍니다. 원본 전체 시설을 브라우저에 내려주지 않습니다. 점 위치는 촬영 범위·실제 밝기·작동 여부의 증거가 아닙니다. 원본 파일 계산과 배포용 파생 자료 계산을 모두 지원합니다.

배경지도 출처는 공간정보 오픈플랫폼 VWorld·국토교통부, 도로망·경로 형상은 OpenStreetMap입니다. 두 출처를 구분해 표시합니다. 무료 이용은 무제한 이용과 다르며 운영 서비스의 이용 조건·등록 도메인은 별도 확인해야 합니다.

## 확인 근거

2026-11-19 저장된 키로 제주 공개 지점의 타일 요청이 HTTP 200·image/png로 응답했습니다. 키 값과 요청 URL은 결과 문서에 기록하지 않았습니다. 공식 샘플과 같은 WMTS `Base/{z}/{y}/{x}.png` 형식을 사용했습니다.

- VWorld 공식 예제: https://github.com/V-world/V-world_API_sample
- 공공데이터포털 무료 2D 지도 안내: https://www.data.go.kr/data/3052419/openapi.do

Vercel 공개 배포는 아직 계정 인증이 필요합니다. 키를 저장한 것만으로 외부 배포 환경에 자동 전달되지는 않습니다.

실제 Chromium에서 지도 타일 4개 모두 HTTP 200, 화면 안의 시설 표시 107개, 경로 카드와 지도 강조 연동·화면 이탈 삭제를 확인했습니다. 320/390/430 폭에서 가로 넘침 없음, 브라우저의 키 노출 0·직접 외부 요청 0·JavaScript 오류 0입니다. 706개 공유 대상 파일에서 저장된 키 값 발견 0입니다. 배경지도는 실제 제공사, 도로·시설은 공개 자료이며 현장 검증은 별도입니다.
