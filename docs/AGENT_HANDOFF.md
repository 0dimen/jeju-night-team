# 제주밤길 에이전트 인수인계

기준: 2026년 11월 19일. 코드·시험·실제 API 기록을 대조했습니다. 후속 localhost 연결에서 연동 공개 구간의 자연어 TMAP 선택→날짜→오전/오후→실제 경로→VWorld 지도 한 사례도 실제 브라우저로 확인했습니다. 다양한 표현·실기기 검증은 남았습니다.

## 결론

**실제 장소 검색·선택 → 보행 후보 조회 → 시설 비율 계산 → 지도 표시는 로컬에서 확인했습니다.** 다만 자유로운 자연어 이해, 추천 기준의 적절성, 현장 통행, 실제 민원 운영과 공개 배포까지 검증한 완성 서비스는 아닙니다.

기본 에이전트는 사용자가 선택한 **규칙·문장 틀**입니다. 현재 웹앱이 외부 언어모델로 대화하는 것은 아닙니다. TMAP·VWorld는 실제 지도·경로 API로 연결했습니다. 모델 연결 실험과 현재 웹앱 운영을 구분해야 합니다.

먼저 읽을 문서는 이 인수인계, [실행 방법](../README.md), [현재 상태](../PROJECT_STATUS.md)입니다. 저장소는 `0dimen/jeju-night-team`, 브랜치는 **`feature/open-data-facility-routes`**입니다. main에는 아직 합치지 않았고 공개 접속 주소도 없습니다.

## 아직 구현되지 않았거나 검증하지 않은 것

- ‘제주대학교에서 집으로’ 같은 문장에서 장소 후보를 검색하고 확인하는 대화와 현재 장소 선택 폼의 자동 통합.
- ‘인화초등학교와 동광초등학교 중 어디가 빠른가’처럼 서로 다른 두 목적지의 동시 비교.
- 사람에게 승인받은 문장 정답에 대한 독립 정확도 평가. 제공된 15문장은 AI 보조 초안이며 의미 판정 칸이 미승인 상태입니다.
- 현재 CCTV·조명의 작동·조도·촬영 범위와 보도·장벽·폐쇄 확인. 영상 날짜가 다른 과거 지도 기록을 새 경로의 검증으로 재사용하지 않습니다.
- 실제 사용자 선호에 맞는 가중치. 반경·우회 한도·80m 끝점 차이 검사 등은 현재 연구·입력 건전성 설정이며 안전 기준 승인이 아닙니다.
- 실제 시민 제보의 영구 접수·관리자 권한·검증·게시·새 실제 시설 지표 변경. 현재 실제 경로 비교는 공개 시설 목록을 사용하며 제보 상태를 자동 반영하지 않습니다.
- 실제 휴대폰·Safari·Android 브라우저, macOS·Windows·센터 실기기, 동시 사용자·부하·운영 로그·실제 요금과 계정 한도.
- Vercel 실제 배포·운영 도메인의 인증·서버 계산 자료 포함과 원본 제외 여부. 로컬 ZIP 검사로 원격 빌드 검증을 대신하지 않습니다.

그동안의 화면 폭 320/390/430 검사는 **Linux의 PC Chromium에서 휴대폰 크기를 재현한 검사**입니다. 실제 휴대폰에서 검사한 것으로 전달하지 않습니다.

## 모델 연결 상태

현재 `agent/api.py`는 기본 `NightAgent()`를 생성하며 모델 공급자를 넣지 않습니다. 키를 저장하거나 `levels.yaml`의 기본 이름만 바꿔도 웹앱이 자동으로 모델 모드가 되는 구조는 아닙니다. 명령행의 `--level`·`--config` 실험 실행과 웹앱 생성부를 구분해야 합니다.

과거 합성 실험에서는 Gemini·Ollama의 실제 호출 기록이 있습니다. 따라서 모델 부분을 모두 ‘가짜 응답만 시험’했다고 설명하는 것도 정확하지 않습니다. 그러나 이는 합성 입력·개발 장비의 별도 실험이며 현재 웹앱의 실제 사용자 품질을 검증한 결과가 아닙니다. Anthropic·OpenAI는 당시 키가 없어 실제 호출을 하지 않았습니다. 기본 규칙·문장 틀 선택은 유지합니다.

현재 서버에서 개인 문장·주소를 외부 언어모델에 보내지 않습니다. 모델을 추가할 때 데이터 전달 범위·이용 조건·출력 숫자 대조·실패 시 규칙 대체를 다시 확인해야 합니다.

맥에서 지금 접속하는 방법은 [localhost 연결 안내](LOCALHOST_CONNECTION.md)를 따릅니다.

## 실행과 확인 순서

```bash
git clone --branch feature/open-data-facility-routes https://github.com/0dimen/jeju-night-team.git
cd jeju-night-team
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-base.txt
.venv/bin/python -m uvicorn agent.api:app --host 127.0.0.1 --port 8000
```

로컬 브라우저에서 `http://127.0.0.1:8000/app`을 엽니다. 실제 검색·보행·배경지도는 서버에 `VWORLD_API_KEY`와 `TMAP_APP_KEY`가 필요합니다. 도메인 조건이 필요하면 실제 등록 주소를 `VWORLD_DOMAIN`에 설정합니다. 파일에 저장한 키는 서버 시작 전에 별도로 불러와야 합니다. 키 값·키 파일을 Git·채팅에 올리지 않습니다.

첫 확인에는 개인 집 대신 공개 장소를 사용합니다.

1. 장소 선택 영역에서 삼무공원과 누웨마루거리를 검색하고 주소를 보고 각각 선택합니다.
2. 날짜와 24시간 시각을 정해 비교합니다. 후보 출처·제공 거리·형상 기준 시설 비율·끝점 차이를 확인합니다.
3. 배경지도 버튼을 누르고 시설점·선택 카드 강조를 확인합니다.
4. 다른 화면으로 이동하거나 새로고침한 뒤 검색·선택·결과가 지워졌는지 확인합니다.
5. 공개 구간 대화에서 TMAP 선택·날짜·오전/오후를 실제로 이어 확인합니다. 파이에서는 한 사례를 실제 확인했고, 맥과 추가 표현은 다음 담당의 확인 항목입니다.

### 연결할 API 구분

| API | 현재 기본 동작 |
|---|---|
| `/agent/chat`, `/agent/conversation`, `/routes/compare` | 기존 합성 엔진 시연. 실제 길찾기라고 연결하지 말 것 |
| `/research/agent/conversation` | 공개 두 구간 대화, TMAP 또는 공개 도로망 선택 |
| `/maps/places/search` | 실제 검색 후보. 자동 선택 없음 |
| `/research/routes/selected` | 선택 좌표의 실제 TMAP·시설 비교, 서버 경로 캐시 없음 |
| `/research/routes/facilities` | 공개 두 구간의 오프라인 도로망 탐색 |
| `/research/routes/tmap` | 공개 두 구간의 TMAP 옵션 비교 |
| `/reports/preview` | 저장 없는 분류 후보·추가 확인 |

`/health`의 `synthetic` 표시는 기본 시연 엔진의 상태입니다. 실제 연구용 API까지 모두 합성이라는 뜻은 아닙니다. `/runtime/status`의 자료 연결은 파일 연결 상태, `/maps/vworld/status`는 키 설정 여부이며 제공사의 현재 인증 성공을 보증하는 검사는 아닙니다.

마지막 전체 실행 기록은 306개 통과·의존성 경고 1개입니다. 후속 localhost에서는 실제 브라우저 통합 한 사례를 별도로 확인했으며 전체 시험은 반복하지 않았습니다. 브라우저 검사는 `tests/browser/run_facility_app_smoke.py`, `run_vworld_app_smoke.py`, `run_selected_app_smoke.py`이며 현재 설치된 Linux Chromium 경로를 사용합니다. 새 장비에서는 경로·의존성을 먼저 맞춥니다. 마지막 두 검사는 실제 API를 부르므로 키·이용 한도를 확인합니다.

## 배포 담당에게 전달할 것

- 저장소 루트·FastAPI·현재 기능 브랜치를 사용합니다. `client/`만 올리면 Python 계산 API가 연결되지 않습니다.
- Vercel 계정과 서버 환경변수, 실제 배포 도메인을 연결합니다. 공개 배포는 아직 하지 않았습니다.
- 빌드 명령은 `python scripts/build_vercel_data.py`, 진입점은 `app.py`입니다. 로컬 원본 개발 실행과 배포용 계산 자료 실행을 구분합니다.
- 조명 89,933행, 표준 CCTV 네 목적 937행·대체 원본 473행을 서버용 좌표 자료로 사용합니다. 원본끼리 합치지 않습니다. 구간 자료 네 개와 제주 시설 자료 한 개는 약 4.27MB입니다.
- `.vercelignore`와 함수 제외 설정, 실제 함수 파일 목록에서 원본 CSV·키 파일 제외를 확인합니다. Git 빌드는 원본을 빌드 입력으로 읽을 수 있으나 런타임 원본 제외는 별도 확인해야 합니다.
- 시연 접수는 임시 메모리입니다. 운영 서비스의 영구 저장·사용자 권한·민원 처리가 아닙니다.

```bash
.venv/bin/python scripts/build_runtime_archive.py --output /tmp/jeju-preview.zip --include-facility-data
```

이 명령은 커밋된 코드와 공개 계산 자료를 묶습니다. 기존 출력은 덮어쓰지 않습니다. 생성한 ZIP의 원본 제외·키 검사와 별도 실행은 확인했지만 Vercel 실제 빌드는 별도입니다.
