# 세 가지 경로 계산식과 4인 선택 시험

## 결론

**빠른 보행 후보3개를 시간·CCTV·조명 비중이 다른 세 식으로 비교하고, 4명이30문항씩 선택한 결과로 가중치를 조정하는 예비 시험**을 권합니다. 이번에 세 식의 독립 계산 코드와 합성30문항·빈 응답120칸을 준비했습니다. 기본 서비스 순위는 바꾸지 않았습니다.

필지 모양만으로 CCTV 촬영 범위나 조도는 알 수 없습니다. 우선은 ‘시설 인접 구간 비율’을 쓰고, 카메라 방향·각도·장애물 근거가 확보된 경우에만 ‘가정한 가시 구간’을 별도 계산하는 단계로 나눕니다. 네 사람의 선택은 초기 선호를 확인하는 자료이며 전체 이용자의 안전 기준을 검증한 결과가 아닙니다.

## 할 일

1. 같은 출발·도착의 보행 후보 중 예상 시간 순으로3개를 확보합니다. 현재 실제 지도 후보는 지역별2개이므로3개를 확보했다고 표시하지 않습니다. 계산 코드는 입력 후보 중3개를 추릴 뿐 전체 도로망의 최단3개를 생성하지 않습니다.
2. 같은 자료·기준일·반경으로 길이 기준 CCTV·조명 인접 비율을 구합니다. 자료가 없으면 점수를 만들지 않습니다.
3. 아래 세 식의 결과를 비교합니다. 시험용 초기 가중치는 임시값이며 사용자 선택으로 학습한 값이 아닙니다.
4. [합성30문항](../review/route_choice_pilot/QUESTIONS.md)을 네 명에게 동일 조건으로 제시합니다. 답변과 이유를 받은 뒤 검증을 거쳐 가중치 후보를 제안합니다. 자동으로 운영 설정에 반영하지 않습니다.

## 공통 지표

경로r의 길이를 L, 예상 시간을 T, 세 후보 중 가장 짧은 시간을 T₀라고 합니다.

- 시간 비교값 **F = T₀ / T**. 가장 빠른 후보는1, 더 느리면1보다 작습니다.
- CCTV 비교값 **C = CCTV 반경 원들의 합집합 안에 들어가는 경로 길이 / L**.
- 조명 비교값 **H = 조명 반경 원들의 합집합 안에 들어가는 경로 길이 / L**.

C·H는0~1입니다. 화면에는100을 곱한%로 표시합니다. 길이 기준이므로 지도 점의 개수나 시설 개수로 나누지 않습니다. 시설이 여러 개 겹쳐도 한 번만 셉니다. C와H는 서로 다른 지표라 같은 구간이 양쪽에 포함될 수 있고, C+H를 ‘전체 보호 비율’이라고 부르면 안 됩니다.

CCTV와 조명이 **둘 다 가까운 구간**을 보이려면 별도 지표 **B = 두 시설 합집합 영역의 교집합 안 경로 길이 / L**을 계산해야 합니다. ‘둘 중 하나 가까움’은 두 영역의 합집합 비율입니다. 현재 시험식은 C·H를 따로 쓰며 B를 구했다고 표시하지 않습니다.

CCTV50미터는 기존 선택한 비교 출발값입니다. 조명30/50/80미터는 아직 연구 비교 중이며 운영 반경 미정입니다. 시설 위치와 현재 점등·작동은 다릅니다.

## 세 가지 식

아래 점수는 모두0~1 범위의 **선호 비교값**입니다. 안전 확률이 아닙니다. 세 가중치 합계는1입니다.

| 식 | 시험용 초기 식 | 의도 |
|---|---|---|
| 1. 시간 비중 높음 | **S₁ = 0.60F + 0.20C + 0.20H** | 우회 부담을 크게 반영 |
| 2. CCTV 비중 높음 | **S₂ = 0.20F + 0.60C + 0.20H** | CCTV 인접 구간을 크게 반영 |
| 3. 조명 비중 높음 | **S₃ = 0.20F + 0.20C + 0.60H** | 조명 인접 구간을 크게 반영 |

‘시간 비중 높음’도 시설 차이가 크면 가장 빠른 길과 다른 길을 고를 수 있습니다. 후보들의 지표 범위가 다르면0.60이라는 계수만으로 실제 선택 영향이60%라고 해석할 수 없습니다. 시험에서 이 점을 확인합니다. 실제 반경·위치 불확실성도 함께 비교합니다.

각 식에서 가장 높은 후보를 표시하되, **세 식이 같은 경로를 고르면 중복 추천임을 표시합니다.** 서로 다른 추천3개를 만들기 위해 낮은 점수의 길을1위라고 바꾸거나 없는 길을 만들지 않습니다. 같은 점수면 공동1위로 표시합니다. 필요하면 서로 다른 후보3개 전체를 보여주고 식별1위 표시를 붙입니다.

예를 들어 완전 합성 후보 A(10분,C20%,H20%), B(15분,C90%,H20%), C(15분,C20%,H90%)는 세 식에서 각각A/B/C가1위입니다. 이 예시는 기능 확인용이며 실제 경로가 아닙니다.

## 각도·거리·가림을 추가하는 방법

카메라 위치p, 설치 방향θ, 수평 시야각α, 가정 거리d를 안다면 경로점x에 대해 다음 조건을 검사할 수 있습니다.

**가정 가시점(x) = [거리(p,x) ≤ d] × [방향 차이(방위(p→x),θ) ≤ α/2] × [중간 장애물 없음]**

해당 조건을 만족하는 경로의 합집합 길이를 L로 나누면 가정한 가시 구간 비율입니다. 점 표본만 세어 비율을 내는 대신 경로 선분을 충분히 세분하거나 경계 교차를 계산하고 오차를 확인해야 합니다. 이 가시 계산은 아직 구현·실자료 적용하지 않았습니다.

- **필지 경계는 건물 벽이 아닙니다.** 건물 외곽선·높이와 담장·수목 등 가림 정보를 별도로 봐야 합니다.
- 필지·도로 각도는 주변 공간 방향의 단서일 뿐 카메라 설치 방향이나 시야각을 결정하지 못합니다.
- 공개 CCTV의 ‘촬영방면’ 설명만으로 정확한 방위·렌즈·높이를 채우지 않습니다. 방향을 모르면 모름으로 두거나 여러 가정의 범위를 제시합니다.
- 조명은 설치 높이·배광·광속·가림·수목·시간대가 필요합니다. 필지 모양과 거리만으로 실제 밝기를 계산했다고 표현하지 않습니다.
- [Axis의 렌즈 기술 문서](https://whitepapers.axis.com/en-us/lenses-in-surveillance)는 시야각이 렌즈·센서 조건과 관련됨을 설명합니다. 확인일2026-11-18. 특정 제조사의 값을 현재 공개 CCTV에 대입하지 않습니다.

## 30문항×4명 시험 설계

같은 합성 질문30개를 네 명에게 각각 제시하므로 **응답은 최대120개, 독립된 참여자는4명**입니다. 서로 다른 사람120명을 조사했다고 표현하지 않습니다. 실제 집 주소·현재 위치·실명은 받지 않고 R01~R04로 구분합니다.

- Q01~18: 시간·CCTV·조명을 교환하는 선택18문항.
- Q19~22: 모든 지표에서 유리한 후보가 있는 확인4문항. 사람 점수나 능력을 평가하지 않고 문항 이해·숨은 선호를 점검합니다.
- Q23~26: 동일·근소 차이4문항.
- Q27~28: 앞선 상황을 다른 표시 순서로 반복한2문항. 반복 일관성을 보되 일반 성능 표본을 늘린 것으로 세지 않습니다.
- Q29~30: 시설 자료가 없는2문항. 판단 보류·자료 부족 처리 선호를 확인하며 결측을0으로 채워 가중치를 맞추지 않습니다.

선택지는A/B/C, 차이 없음, 자료 부족·판단 보류입니다. 가장 큰 이유와 선택 확신은 선택적으로 받습니다. 식의 이름·가중치·추천1위를 먼저 보여주지 않습니다. 문항별 A/B/C 배치를 섞었고 참여자별 문항 순서도 달리 준비했습니다. 문항 순서는 `presentation_order.csv`에 있으며 화면이나 설문 도구로 옮길 때 이를 적용합니다. 문항의 실제 속성은 같은 상태로 유지합니다.

## 응답을 가중치로 바꾸는 방법

1. 원응답을 보존하고 무응답·차이 없음·보류·불완전 지표를 별도 집계합니다. 반복2개·확인4개는 가중치 맞춤의 주 표본에서 분리합니다.
2. 각 후보의 F/C/H로 **조건부 로짓 선택 모형**을 맞추는 방안을 사용합니다. 효용 U=wF·F+wC·C+wH·H, w는0이상·합계1로 제한합니다. 선택 확률은 exp(βU)를 문항 안 세 후보의 합으로 나눈 값입니다. β는 선택의 일관성 정도이며 세 계수와 구분합니다. 최적화는 수치적으로 안정한 로그합계 계산을 사용합니다.
3. 단순 비교로는 가장 빠른 후보, 동일 가중치, 초기 세 식의 선택 일치율을 함께 계산합니다. 복잡한 식이 더 낫다고 미리 정하지 않습니다.
4. 네 명 중 한 명을 빼고 세 명으로 가중치를 맞춘 뒤, 남은 한 명의 선택을 예측하는 검사를 네 번 합니다. 같은 사람 응답을 무작위로 학습·검증에 섞어 과대평가하지 않습니다.
5. 개인별 가중치·세 명씩의 가중치가 얼마나 다른지 보여줍니다. 참여자4명으로는 대표성이나 안정적인 신뢰구간을 주장하지 않습니다. 세 식의 차이가 작으면 더 단순한 방식을 유지할 수 있습니다.
6. 자료·표현·반경이 바뀌면 선택도 바뀔 수 있습니다. 합성 문항 선택과 실제 지도에서 길을 고르는 검증은 구분하고, 후속 참여자를 늘리거나 실제 후보로 재확인합니다.

응답을 아직 받지 않아 학습된 가중치·선택 정확도·사용자 만족도 결과는 없습니다. 이번 구현은 세 식 비교와 설문 준비까지만이며 학습기·시야각 추정·운영 연동은 후속입니다.

## 코드와 준비 파일

- `agent/data/route_score_proposal.py`:명시한 세 가중치로 별도 비교. 결측·잘못된 값·후보3개 미만 거부, 공동1위 보존.
- `review/route_choice_pilot/QUESTIONS.md`:전달할30문항. 실제 사용자 주소나 경로가 없는 합성 시험입니다.
- `review/route_choice_pilot/responses_BLANK.csv`:네 명의 빈 응답120칸. 답은 아직 모두 공란입니다.
- `review/route_choice_pilot/questions_SYNTHETIC.json`:문항 설계·반복 대응표. 참여자에게는 식·설계 종류를 숨깁니다.
- `review/route_choice_pilot/presentation_order.csv`:참여자별 제시 순서.

실제 응답을 받을 때는 이 빈 양식의 사본을 접근이 제한된 곳에서 사용하고 응답 원본을 팀 저장소에 올리지 않습니다. 이름·실제 집 주소는 적지 않습니다.

참여자별 분리 검사는 [공식 LeaveOneGroupOut 설명](https://scikit-learn.org/stable/modules/generated/sklearn.model_selection.LeaveOneGroupOut.html)을 참고한 계획입니다. 라이브러리를 설치하거나 실제 응답으로 학습한 결과는 아닙니다. 확인일2026-11-18.

검증: 전체 Python252개 통과(4.63초, 의존성 경고1개). 세 식의 서로 다른 선택·중복 선택·공동1위·결측 거부·입력 불변 검사를 포함합니다. 문항30개·빈 응답120개·참여자별30개 제시·반복 대응·재생성 바이트 동일을 확인했습니다. 문항은 `scripts/build_route_choice_pilot.py --output <새 폴더>`로 다시 준비할 수 있고 기존 결과가 있는 폴더는 거부합니다.
