# TMAP 보행 경로 연결

## 결론

서버의 `TMAP_APP_KEY`로 보행자 경로 API 인증을 확인하고, 공개 두 구간의 경로 옵션과 CCTV·조명 비율 비교를 웹앱에 연결했습니다. 키는 서버의 요청 헤더에만 넣습니다. 사용자 문장·집 주소·키를 URL에 넣거나 저장하지 않습니다.

연동 공개 구간에서 실제 세 옵션은 모두 같은 형상이었습니다. 결과는 한 경로로 묶으며 서로 다른 세 경로를 얻었다고 표시하지 않습니다.

| 항목 | 실제 응답·계산 |
|---|---:|
| TMAP 제공 거리 | 439m |
| TMAP 예상 시간 | 363초, 6분 3초 |
| 반환 형상으로 계산한 길이 | 약 446.4m |
| CCTV 50m 인접 비율 | 30.21% |
| 조명 15m 인접 비율 | 69.30% |
| 요청점과 반환 끝점 차이 | 출발 약 15.8m / 도착 약 5.1m |

제공 거리와 형상 길이는 다릅니다. 시설 비율은 반환 형상의 길이를 분모로 계산합니다. 끝점 연결 차이를 숨기지 않으며 다른 제공사의 경로 수치와 완전히 같은 끝점·측정 방식이라고 단정하지 않습니다. 연동 도착점은 기존 공개 자료의 누웨마루 공중화장실 지도 지점입니다.

## 사용법

서버 환경변수 `TMAP_APP_KEY`를 설정한 상태에서 `/app` → 지도 → 공개 구간·조건 선택 → **‘TMAP 보행 후보 요청·시설 비교’**를 누릅니다. TMAP 경로를 받아 시설 비율을 계산합니다. 이후 VWorld 버튼을 누르면 배경지도·시설·TMAP 경로를 함께 표시합니다. VWorld 키도 서버에 설정되어 있어야 합니다.

현재 두 공개 구간만 지원하며 새 주소·집 위치를 입력해 TMAP에 보내는 기능은 아직 없습니다. 기존 공개 도로망에서 시설 선호 경로를 새로 탐색하는 버튼과 TMAP 옵션 후보를 받는 버튼은 별도입니다. 기본 대화 흐름은 기존 공개 도로망 계산을 유지합니다.

## 비교 기준

TMAP 요청 옵션은 10(최단), 4(대로 우선), 30(최단거리·계단 제외)입니다. 제공사가 서로 다른 길을 반환한다는 조건은 없습니다. 같은 형상이면 하나로 합치고 각 옵션의 제공 거리·시간도 응답에 보존합니다. 실패한 옵션은 별도 표시하며 전부 실패하면 503을 반환합니다. 합성 경로로 대체하지 않습니다.

‘빠른 길’은 받은 후보 중 제공 예상 시간을 비교합니다. CCTV·조명·함께 조건은 기존 연구용 가중치로 후보별 `형상 길이 × [1 + 조명가중치×(1−조명비율) + CCTV가중치×(1−CCTV비율)]`를 비교합니다. 최단 후보 대비 우회 한도를 넘으면 추천에서 제외하고 비교용이라고 표시합니다. 이 가중치가 TMAP에 전달되어 시설 우선 경로를 생성하는 것은 아닙니다. 전 지역의 최적 경로나 안전 점수가 아닙니다.

공개 시설 자료의 배포용 보장 범위를 벗어난 후보는 시설을 0으로 처리하지 않고 제외합니다. 지도·현장 통행 확인은 여전히 미확인입니다.

## 호출·키·저장

- 요청은 서버의 고정 보행 API 주소에 POST합니다. appKey는 헤더에만 넣고 출발·도착 명칭은 일반 표기 start/end를 사용합니다.
- 한 요청에서 최대 세 옵션을 확인합니다. 공개 두 구간의 좌표·거리·시간만 정규화해 1시간 캐시하며 같은 옵션을 매번 다시 호출하지 않습니다. 키가 바뀌면 캐시도 구분합니다.
- 캐시는 임시 폴더이며 Git·배포 원본에 포함하지 않습니다. 만료 응답은 재사용하지 않습니다. TMAP 안내의 저장 데이터 24시간 사용 제한보다 짧게 운영합니다. 임의 사용자 위치를 캐시하는 구조로 확대하지 않았습니다.
- 호출 간 최소 1초 간격과 401/403/429 후 60초 보류를 적용합니다. 이는 제공사 공식 한도 정의가 아니라 앱 자체 호출 조절입니다. 등록한 상품의 실제 무료·유료 한도는 계정에서 확인해야 합니다.
- 키·제공사 오류 본문을 응답하지 않고 표준 HTTP 로그에도 키 가림을 적용합니다. 응답 크기·좌표·연속성·요청 끝점 차이·제공 거리 대비 형상 차이를 검사합니다. 80m 끝점 차이와 거리 오차 기준은 입력 건전성 검사 한도이며 보행 정확도나 사용자 허용 기준 승인이 아닙니다.

## 검증 결과

Python 297개 통과(의존성 경고 1개). 실제 Chromium에서 TMAP 결과를 VWorld 타일 4개와 함께 표시하고 화면 내 시설점 104개·경로 카드 강조·화면 이탈 삭제를 확인했습니다. 320/390/430 폭 검사 통과, 두 키의 브라우저 노출 0·브라우저 직접 외부 요청 0·JavaScript 오류 0입니다. 기존 공개 도로망·대화·합성 접수 검사도 통과했습니다.

서귀포에서도 세 옵션이 모두 같은 경로를 반환했습니다. 제공 거리 307m·예상 267초(4분 27초), CCTV 인접 66.51%·조명 인접 64.73%, 요청 끝점 차이는 약 5.0m/5.7m였습니다. 두 지역 모두 실패한 옵션은 없었습니다. 이 수치를 지역 간 안전 비교에 쓰지 않습니다.

공유 대상 709파일에서 알려진 키 값 발견 0입니다. 시험에는 공개 장소만 사용했습니다. 실제 제공사 형상·응답 원문을 Git에 넣지 않았으며 위 표는 해당 시점의 측정 기록입니다. 장기 보관한 API 응답을 운영 계산에 재사용하는 방식이 아닙니다.
