# 대화 화면과 현장 확인 준비

## 결론

로컬 서버의 `/demo`에서 합성 위치 선택, 날짜·오전·오후 확인, 경로 비교표, 출처 질문과 제보 미리보기를 눌러볼 수 있습니다. 실제 길찾기나 실제 지도 화면은 아닙니다. 실제 집 주소를 입력하지 않습니다.

```bash
.venv/bin/python -m uvicorn agent.api:app --host 127.0.0.1 --port 8000
```

브라우저에서 `http://127.0.0.1:8000/demo`를 엽니다. 합성 위치 선택 → ‘안전한 길 알려줘’ → 날짜 → ‘3시’ → ‘오후’ 순서로 확인할 수 있습니다. 비교값은 CCTV 인접 구간 비율이며 안전 확률이 아닙니다.

## 위치와 대화 처리

페이지의 메모리만 사용합니다. 초기화, 페이지 이탈·뒤로가기 복원, 새로고침 때 입력창·결과·위치를 비웁니다. 위치를 브라우저 저장소에 보관하지 않습니다. 합성 위치 버튼만 제공하며 주소 검색이나 외부 지도 요청은 하지 않습니다. 제보는 미리보기만 하며 저장·게시하지 않습니다. 고정한 정적 파일 네 개만 제공합니다.

API와 화면은 로컬 시연용입니다. 실제 서비스 인증·사용자별 접근 제한·운영 환경 설정은 완료하지 않았으므로 외부에 공개하는 명령은 안내하지 않습니다.

## 현장 확인표 준비

```bash
.venv/bin/python scripts/prepare_field_review.py \
  --routes data/route_examples/SYNTHETIC_routes.geojson \
  --output /tmp/route-field-review
```

`field_review.csv`는 경로 선분마다 통행 가능 여부, 횡단 지점, 야간 밝기, 공사·폐쇄, 시설 현재 상태를 적을 빈 표입니다. 확인 날짜·시각과 확인 방법·근거를 함께 적습니다. `summary.json`은 원본 파일 지문·출처·지도상 거리·제공 추정 시간입니다. 확인표 생성은 실제 확인이나 채택을 뜻하지 않습니다. 개인 주소를 포함한 입력·출력은 Git에 올리지 않습니다.

현장에서는 혼자 위험한 구간에 들어가지 말고 공개된 통행 가능 구역에서 확인합니다. 확인할 수 없는 항목은 ‘미확인’으로 남기며 정상으로 간주하지 않습니다. 어두워 보인다는 주관적 관찰을 조도 실측값으로 적지 않습니다. CCTV 인접 여부를 작동·촬영 범위 확인으로 바꾸지 않습니다.

## 검사와 남은 작업

Python 검사239개 통과(의존성 사용 중단 예정 경고1개), 페이지 상태 모의검사5개 통과. 설치된 Chromium으로 실제 화면의 대화·비교표·초기화·뒤로가기·새로고침·출처·제보·예약 안내·저장소 비사용을 확인했습니다. 화면의 외부 요청0, 자바스크립트 오류0입니다. 브라우저 검사는 로컬 Linux에서 수행했습니다.

선택 브라우저 검사 의존성은 `requirements-browser-test.txt`입니다. 설치된 Chromium이 필요하며 추가 브라우저를 다운로드하지 않습니다.

```bash
.venv/bin/python -m pip install -r requirements-browser-test.txt
.venv/bin/python tests/browser/run_demo_smoke.py
node --test tests/browser/test_page_conversation.mjs
```

남은 항목은 실제 원본의 이용 조건 확인, 현장 확인, 실제 지도 화면 연결, 사용자 문장의 사람 검토, 센터 기기 실행입니다. 미확인 자료의 승인 표시를 켜거나 추천 가중치를 새로 정하지 않았습니다.
