# 실제 데이터·에이전트 시험 배포

## 결론

웹 화면과 Python 에이전트·시설 경로 계산을 한 FastAPI 앱으로 배포합니다. 서로 다른 서버 주소를 연결할 필요 없이 같은 주소에서 요청합니다. 기본 에이전트는 사용자가 선택한 규칙·문장 틀이며, 유료 모델이나 Gemini에 사용자 위치·문장을 보내지 않습니다.

## 직접 확인할 것

접속 후 상단에 ‘공개 경로 자료 연결됨 · 규칙형 에이전트 연결됨’과 준비 시각이 표시됩니다. 지도 → 공개 구간 대화에서 `연동 공개 구간 2026-11-20 오후 9시`를 입력해 실제 후보를 확인합니다. 기존 합성 대화·접수는 별도 시연입니다. 접수 기록은 임시 메모리이므로 새 서버 실행에서 사라질 수 있으며 실제 민원 접수가 아닙니다.

임의 주소·GPS·배경지도·로드뷰·제주 전체 도로망은 아직 연결하지 않았습니다. 카카오·TMAP 키를 받으면 이 부분을 추가할 수 있습니다. 현재 공개 두 구간 계산에는 추가 키가 필요하지 않습니다.

## 원본 제외와 서버 데이터

`python scripts/build_vercel_data.py`가 원본 좌표 수정·목적 선택 검사 후 계산 자료 4개(두 구간×두 CCTV 원본)를 `runtime/facilities/`에 만듭니다. 전체 공개 원본 CSV·API 원문을 넣지 않고 해당 도로 범위와 최대 반경에 필요한 시설 좌표·도로망·출처만 포함합니다. 계산용 좌표는 서버에 존재하며, 원본을 제외한다는 뜻이 모든 좌표를 제거한다는 뜻은 아닙니다.

원본과 파생 계산의 경로·수치가 같은지 16조건으로 비교합니다. 반경·가중치를 바꾸면 서버가 다시 계산하며 미리 저장한 추천 문장을 보여주는 방식이 아닙니다. 화면이 요청한 경로 좌표는 응답하지만 서버 계산 자료 전체를 정적 파일로 제공하지 않습니다.

Vercel의 함수 제외 설정(`vercel.json`의 `excludeFiles`)에 `data/open/`·비밀 파일·개발 환경·실험·검토 자료를 넣었습니다. `.vercelignore`는 Git 연결 배포의 빌드 입력에도 적용되므로 `data/open`을 넣지 않습니다. 넣으면 빌드 명령이 원본을 찾지 못해 실패합니다(2026-11-20 확인). 원본은 빌드 입력에만 쓰이고 함수 실행물에는 들어가지 않습니다. 로컬 CLI 배포 전에는 위 생성 명령을 실행해야 합니다. Git 연결 배포는 비공개 저장소의 원본을 빌드 입력으로 읽고, 생성한 계산 자료만 함수 실행물에 포함합니다. 빌드 서비스에도 원본을 전혀 전달하지 않아야 한다면 로컬 생성 후 CLI 방식으로 배포해야 합니다.

## 계정 연결과 변경 확인

지속적으로 같은 주소를 사용하려면 Vercel 계정에 팀 저장소를 연결하고 이 작업 브랜치를 시험 배포 대상으로 사용합니다. main에는 아직 합치지 않았습니다. 같은 브랜치의 새 커밋을 시험 배포하고 표시된 준비 시각과 실제 계산으로 변경 반영을 확인합니다. Vercel의 별도 배포 주소는 버전별로 달라질 수 있으므로 카카오에는 사용할 고정 주소를 등록해야 합니다.

배포 설정은 `vercel.json`, 진입점은 `app.py`, 의존성은 `requirements.txt`입니다. 비밀키를 Git에 추가하지 않습니다. 필요할 때 Vercel 프로젝트의 Environment Variables에서 설정합니다. 현재 기본 모드는 모델 키가 필요하지 않습니다.

Vercel 공식 근거(2026-11-19 확인):

- https://vercel.com/docs/frameworks/backend/fastapi
- https://vercel.com/docs/project-configuration/vercel-json

자동 검사와 로컬 원본 제거 실행은 실제 Vercel 빌드 성공·외부 접속 성공을 대신하지 않습니다. 배포 결과는 별도 기록합니다.

## 이번 결과

2026-11-19 현재 Python 283개 통과(의존성 경고 1개), 원본 없는 별도 폴더에서 화면·연결 상태·실제 대화 경로·계산 자료 직접 다운로드 불가를 확인했습니다. 원본과 계산용 자료의 결과를 두 지역×두 원본×네 조건, 총 16조건에서 비교했습니다. 계산 자료 4개는 약 1.9MB이며 전체 원본은 포함하지 않습니다. 계산 자료만 연결한 Chromium의 3개 화면 폭×5화면·대화·접수 검사도 통과했습니다.

**Vercel 외부 배포는 아직 하지 못했습니다.** 현재 계정 로그인 정보가 없고, CLI의 로그인 없는 임시 배포 시도도 `login_required`로 거부되었습니다. 이 결과는 자동 승인 검토 거절이 아니라 Vercel 서비스의 인증 요구입니다.

계정 연결 후 계속할 방법:

1. Vercel에서 팀 GitHub 저장소 `0dimen/jeju-night-team`을 Import합니다.
2. main은 아직 새 배포 설정이 없으므로, 시험 배포할 Git 참조를 `feature/open-data-facility-routes`로 지정합니다. 프로젝트 생성 화면에서 지정할 수 없으면 생성 후 Git 설정과 새 배포의 브랜치 선택에서 지정합니다.
3. FastAPI, 저장소 루트, 준비된 Build Command와 Python 의존성을 사용합니다. Root Directory를 `client/`로 설정하면 안 됩니다.
4. 배포 URL에서 `/runtime/status`와 공개 구간 대화를 확인합니다. 실제 외부 빌드의 원본 제외 여부도 함수 출력 파일 목록으로 확인해야 합니다.

이 서버에서 직접 배포하려면 Vercel CLI 로그인 연결이 필요합니다. 비밀 토큰을 채팅에 붙이지 않습니다. 새로 발생하는 계정·요금 선택은 이번 코드 변경으로 확정하지 않았습니다.
