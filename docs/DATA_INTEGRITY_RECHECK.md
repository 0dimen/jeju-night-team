# 원본 재다운로드와 CCTV8행 원인 점검

## 결론

CCTV·제주시 조명·서귀포 조명 원본을 공식 공개 다운로드 절차로 다시 받았습니다. **세 원본 모두 기존 파일과 바이트 지문이 같았습니다.** 다운로드 중 잘리거나 오류 HTML을 CSV로 저장한 정황은 발견되지 않았습니다. 그러나 파일을 제대로 받았다는 사실과 제주 전체 시설이 빠짐없이 들어 있다는 사실은 다릅니다.

CCTV는8대가 아니라 **공개 원본479행 중 생활방범8위치행·기재37대**입니다. 원본 자체에8행만 있고, 기존 사용자 선택대로 생활방범만 추려서8행이 남았습니다. 좌표 오류 때문에 나머지 방범 행을 버린 것은 아닙니다. 왜 제공처가 방범 위치를8행만 공개했는지는 확인되지 않았습니다.

## CCTV가8행만 남은 과정

1. 미리보기20행이 아니라 **원본 첨부파일**을 받았습니다. 원본 파일 크기는64,389바이트이고 미리보기 파일은 별도입니다.
2. 원본 전체479행의 목적은 교통단속348·어린이보호100·시설물관리17·기타6·생활방범8입니다.
3. 생활방범만 선택하는 기존 정책을 적용했기 때문에8행이 남았습니다. 이8행에는 원본 카메라대수 합계37대가 적혀 있습니다.
4. 원본 메타데이터는 자동 갱신이 꺼져 있고 페이지 수정일은2025-09-30입니다. 원본 행의 날짜는 생활방범/어린이보호/기타2022-12-15, 시설물관리2023-04-11, 교통단속2024-07-29로 서로 다릅니다. 페이지 수정일을 시설 조사일로 쓰면 안 됩니다.
5. 따라서 ‘내려받다 잘린 결과’라는 근거는 없고, **현재 공개 첨부파일의 좁고 불균형한 수록 범위와 생활방범 목적 필터**가 직접 원인입니다. 다만 미등록·공개 제외·공급자 누락 중 무엇이 더 근본적인 원인인지는 제공처 확인 없이 단정하지 않습니다.

기존 공식 관제 보고서의 과거 생활방범 집계와도 규모가 달라 이 파일을 제주 전체라고 볼 수 없습니다. 다만 그 집계를 개별 카메라 좌표로 바꾸거나 현재 대수로 사용하지 않습니다.
