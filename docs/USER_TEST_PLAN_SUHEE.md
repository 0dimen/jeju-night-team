# 수희 사용자 시험 계획: 실제로 써 보는 사람의 눈으로

2026년 11월 20일 08:00 시작 · 약 50분 · 주소 https://jeju-night-team.vercel.app/app

## 결론

**도민·관광객·밤에 혼자 걷는 사람이 되어 서비스를 직접 써 보고, 헷갈리거나 믿기 어려운 곳을 찾습니다.** 기능이 "되는지"보다 "처음 쓰는 사람이 이해하고 믿을 수 있는지"를 봅니다.

- **소요 시간:** 약 50분 (경로 20분, 제보 15분, 긴급 표현 10분, 정리 5분)
- **준비물:** 휴대폰(위치 권한을 켤 수 있는 것), 노트북 또는 두 번째 화면, 화면 캡처 방법
- 혜수는 시연·기획서 문구를 따로 확인합니다. 이 문서는 사용자 체감만 다룹니다.

## 시작 전 규칙

1. **실제 집 주소, 실제 전화번호를 넣지 않습니다.** 공개 장소 이름과 가짜 번호 `010-0000-0000`만 씁니다.
2. **112나 119에 실제로 전화하지 않습니다.** 긴급 문장은 연기 문장으로만 입력합니다.
3. 이상한 점이 있으면 바로 **화면을 캡처**하고 **"어느 화면에서 무엇을 눌렀는지"**를 메모합니다.
4. 결과 칸에는 ✅(기대대로) / ⚠️(되지만 헷갈림·느림) / ❌(안 됨) 중 하나를 적습니다.
5. **체감 점수**는 1~5점입니다. 1점은 "전혀 이해 안 됨·못 믿겠음", 5점은 "바로 이해됨·믿을 만함"입니다.

## 이미 알려진 문제 (다시 찾지 않아도 됩니다)

새벽 QA에서 찾은 문제입니다. 지금도 그런지만 확인하고 ✅/❌로 표시하세요.

- 긴급 표현은 04:40에 보강했습니다. QA 문장은 모두 112 안내가 나옵니다. **수희가 직접 만든 문장에서 놓치는 것을 찾는 것**이 C 시험의 목적입니다.
- 제주시청 → 탑동광장은 비교 기준을 바꿔도 추천 경로가 바뀌지 않습니다. CCTV 기준인데 CCTV 비율이 가장 낮은 길이 "추천"으로 나옵니다.
- "탑동광장" 검색 결과 맨 위가 편의점이고, 같은 장소가 여러 번 나옵니다.
- 화면 제목은 "두 경로 비교"인데 경로가 3개 나올 수 있습니다.
- 접수 완료 화면의 "검토한 뒤 다음 경로 분석에 반영해요"는 아직 구현되지 않은 기능입니다.

### C. 긴급 표현 (노트북 또는 휴대폰, 약 10분)

**제보** 탭에서 위치·유형을 아무거나 고른 뒤 **상세 설명 작성** 칸에 아래 문장을 넣고 **제보 내용 확인**을 누릅니다. 112·119 안내가 먼저 나오면 ✅, 시설 설명을 다시 물으면 ❌입니다. **실제 신고는 하지 않습니다.**

| 26 | 내가 직접 만든 위험 상황 문장 ① | 112 안내 | | 문장: |
| 27 | 내가 직접 만든 위험 상황 문장 ② | 112 안내 | | 문장: |
| 28 | 내가 직접 만든 위험 상황 문장 ③ | 112 안내 | | 문장: |

| 30 | 내가 직접 만든 위험 상황 문장 ⑤ | 112 안내 | | 문장: |

문장은 실제 사람이 급할 때 쓸 법한 말로 씁니다. 예: 반말, 띄어쓰기 없음, 짧은 말("무서워 도와줘"), 사투리.

## 결과 보내는 방법

**09:00까지 팀 단톡방에** 아래 양식으로 올립니다. 혜수가 모아 기획서에 반영합니다. 표 전체를 캡처해도 됩니다.

```
[수희 사용자 시험 결과]
- 시험 시각·기기: (예: 08:05~08:55, 아이폰 사파리)
- ❌ 목록: 번호 · 한 줄 설명 · 캡처 파일 이름
- ⚠️ 목록: 번호 · 한 줄 설명
- 긴급 문장: 넣은 문장 수 __ / 112 안내 나온 수 __ (안 나온 문장 그대로 적기)
- 체감 점수 평균: 경로 __ / 제보 __
- 가장 헷갈린 화면 1개와 이유:
```

## 기획서·시나리오에 쓸 수 있는 관찰 포인트

- 처음 본 사람이 서비스를 한 문장으로 어떻게 설명했는지(1번)
- 추천 이유를 사용자가 자기 말로 설명할 수 있었는지(5번). 설명이 어렵다면 "근거를 보여 주는 서비스"라는 기획 의도와 어긋납니다.
- 시간대·현재 작동 상태를 모른다는 안내가 신뢰를 높였는지, 불안하게 했는지
- 실제 휴대폰 GPS 결과(14번). 제출 문서에 "휴대폰 실기기 확인"을 쓸 수 있는지 정합니다.
- 긴급 문장 인식률. 발표에서 "긴급 상황은 112를 먼저 안내합니다"라고 말해도 되는 수준인지 판단합니다.
- 새로고침하면 제보가 사라지는 동작을 사용자가 개인정보 보호로 받아들였는지
