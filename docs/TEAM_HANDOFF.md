   - 경로 카드와 지도가 나오면: 계획대로 사용자 테스트와 시연 준비를 진행합니다.

5. **발표에서 하지 않을 말:** "모든 긴급 상황을 인식한다", "검증된 제보가 경로에 반영된다", "안전한 길". 이유는 4장에 있습니다.

## 5. 실행과 배포

로컬 실행(Python 3.13):

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python scripts/check_basic_runtime.py   # passed: true 확인
.venv/bin/python -m pytest -q --ignore=tests/browser
.venv/bin/python -m uvicorn app:app --host 127.0.0.1 --port 8000
```

브라우저에서 `http://127.0.0.1:8000/app`을 엽니다. 장소 검색과 경로 비교를 하려면 아래 환경변수가 필요합니다.

| 환경변수 | 용도 |
|---|---|
| `VWORLD_API_KEY` | 장소 검색·배경지도 |
| `VWORLD_DOMAIN` | VWorld 키에 등록한 주소가 실행 주소와 다를 때만 |
| `TMAP_APP_KEY` | 보행 경로 |
| `DATA_GO_KR_SERVICE_KEY` | CCTV 원본을 새로 받는 수동 스크립트에서만 |

- **키 값은 Git·채팅·문서에 절대 넣지 않습니다.** `.env.example`을 `.env`로 복사해 로컬에서만 채웁니다.
- Vercel: 프로젝트 Settings → Environment Variables에 위 이름으로 넣고 Redeploy 합니다. 빌드 명령은 `python scripts/build_vercel_data.py`이며 공개 원본에서 계산용 자료만 만듭니다. 자세한 설명은 [Vercel 배포](VERCEL_PREVIEW.md)에 있습니다.
- `.vercelignore`에 `data/open`을 다시 넣으면 빌드가 실패합니다.
- 배포 주소에서 실제 브라우저 검사를 하려면 `JEJU_TEST_BASE_URL=https://jeju-night-team.vercel.app`을 주고 `tests/browser/run_service_app_smoke.py`를 실행합니다. 이 검사는 Linux의 Chromium 경로를 기준으로 작성되어 있습니다.

- 실제 주소, 개인 전화번호, 위치 기록, 키를 저장소·채팅·스크린샷에 넣지 않습니다. 시험에는 공개 장소와 가짜 번호(010-0000-0000)만 씁니다.
- 사람의 판정은 사람이 씁니다. AI가 만든 후보를 사람 판정이나 정답으로 바꾸어 적지 않습니다.
- 확인하지 않은 것은 '미확인'으로 적습니다. 예시·시범 운영 기능을 실제 운영처럼 표현하지 않습니다.
- 시설 인접 비율을 안전 확률이나 촬영 범위로 설명하지 않습니다.
