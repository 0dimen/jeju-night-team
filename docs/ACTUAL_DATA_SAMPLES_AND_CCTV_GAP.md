# 실제 원본 개수·10번째 줄과 CCTV 대체 후보

## 결론

**보유 원본의 생활방범은 위치8행, 기재 카메라37대입니다. 제주 전체 생활방범 CCTV가8대라는 뜻이 아닙니다.** 현재 앱은 합성 계산이며 아래 자료는 실제로 내려받아 연구용으로 정리한 원본입니다. 아직 실제 서비스 지표로 채택하지 않았습니다.

생활방범 후보가 모두 서귀포이고2022-12-15 기준이라 제주 전역 추천에 부족합니다. 새1순위 후보는 행정안전부의 일간 갱신 CCTV정보 조회서비스입니다. 인증키가 필요하여 이번에는 원본 조회·제주 목적별 행수 확인까지 완료하지 못했습니다. 목록을 찾은 것과 새로운 위치 데이터를 확보한 것을 구분합니다.

기재 대수는 현재 작동 대수가 아닙니다. 어린이보호100행은 목적이 다르므로 자동으로 생활방범에 합치지 않았습니다. 학교 주변 공개 도로에 실제로 관련되는지 별도 판단할 수 있는 기존 후보입니다.

제주시는 축 교환 의심16,155행 중5행의 종류도 미기재라 중복 집계하지 않습니다. 서귀포103행은 좌표 빈칸입니다. 같은 좌표 행은 자동 병합하지 않았습니다.

기본 실행 화면이 실제로 계산하는 데이터는 합성 CCTV설치점7개·합성 경로2개입니다. 둘 다10번째 항목은 없습니다. 수집한 실제 원본을 이미 앱 계산에 연결했다고 표시하지 않습니다.

보행은 실제 지도 후보4개(지역별2개)이며10번째 경로는 없습니다. 경로의10번째 좌표를10번째 경로로 출력하지 않습니다. 실제 활동·유동인구 원본은 앱에 연결하지 않았으며, 제공된 합성 통계를 실제 데이터로 세지 않습니다.

## 원본 파일의10번째 줄

**헤더를1번째 줄로 센 파일10번째 줄**을 그대로 출력합니다. 이 세 원본은 헤더1줄이고 데이터 행 중 줄바꿈이 없어 데이터9번째 행입니다. ‘헤더 제외 데이터10번째 행’은 다음 절에 따로 표시했습니다.

CCTV 열 순서: 관리기관명, 도로명주소, 지번주소, 설치목적, 카메라대수, 카메라화소수, 촬영방면정보, 보관일수, 설치연월, 위도, 경도, 데이터기준일.

```csv
제주특별자치도,제주특별자치도 서귀포시 마소물로8번길 30,제주특별자치도 서귀포시 보목동 891,어린이보호,3,0,보목초 후문,30,,33.245249,126.600221,20221215
```

제주시 조명 열 순서: 종류, 법정동, 지번주소, 위도, 경도.

```csv
보안등,봉개동,제주특별자치도 제주시 봉개동 1677,33.49592346,126.5998507
```

서귀포시 조명 열 순서: 등종류, 행정동, 소재지 주소, 상세위치, 위도, 경도, 데이터기준일.

```csv
가로등,대정읍,제주특별자치도 서귀포시 대정읍 상모리3396-2,,33.23049545,126.2621841,2025-07-25
```

빈 필드는 원문 그대로 비워두었습니다. 생활방범만 선택한 결과는8행이라10번째 행이 없습니다.

## 다음 처리

우선 새 API 또는 최신 원본에서 제주 행을 확보하고 기존479행과 비교합니다. 접근이 막힌 동안 교통단속을 방범으로 바꾸거나 학교 대표점을 카메라 좌표로 만들어 쓰지 않습니다. 조명 자료는 별도 참고 지표로 유지하고 CCTV자료가 없는 구간은0점 대신 자료 부족으로 표시합니다.
