# 다음 개발 상태

## 완료

- 날짜·오전/오후와 위치 확인을 마치면 합성 비교 요청까지 이어집니다.
- 비교표는 CCTV 인접비율×100, 거리·시간, 빠른 경로와 시설 인접성이 높은 경로를 구분해 보여 줍니다. 기존 엔진 순위는 바꾸지 않습니다.
- 자료 없음·검토 중은 0점으로 바꾸지 않습니다.
- ‘초기화’·‘취소’로 상태를 비웁니다. 서버가 위치를 기억하는 기능은 추가하지 않았습니다.
- 전체211개 자동검사 통과.

## 이어서 할 일

1. 실제 보행 경로와 자료 사용·좌표 근거를 확보합니다. 현재 비교는 합성입니다.
2. 서로 다른 목적지 비교는 같은 목적지의 대안 경로 비교와 구분해 구현합니다.
3. 실제 페이지에서 이탈 시 상태 삭제·요청 중단을 연결합니다.
4. 새 문장과 사람이 확인한 의도로 입력 처리를 개선합니다.
5. 센터 컴퓨터에서 기본 점검을 실행합니다.

변경은 기능 브랜치에서 검사를 통과한 뒤 다른 팀원의 검토를 받아 합칩니다. 이 문서 작성이나 자동 검사 통과는 실제 자료 채택·외부 공개 승인이 아닙니다.

## 페이지 연결 준비

메모리 상태 연결 모듈과 페이지 이탈·복원·늦은 응답 방지 검사5개를 추가했습니다. 실제 지도 화면은 별도입니다. docs/PAGE_CLIENT_INTEGRATION.md를 따라 화면마다 인스턴스를 만들고 이동 시 해제합니다.
