# 제보 점수 반영 범위 후보와 구현

## 결론

승인된 제보 주변을 지나는 길이에 추가 비용을 주는 비교 기능을 구현합니다. **반경·반영 강도는 미확정 후보이며, 배포 서비스에는 적용하지 않습니다.** 사용자의 이번 지시는 후보 작성과 선행 구현이며 특정 기준값 승인은 아닙니다.

## 결정할 후보

| 범위 | 계산 | 장점 | 주의점 |
|---|---|---|---|
| 안내만 | 점수 유지, 해당 경로에 제보 안내 | 기존 순위 유지 | 추천 순위에는 영향 없음 |
| 승인 제보의 인접 구간 추가 비용(이번 구현) | 기존 비교 비용 + 반영 강도 × 제보 인접 길이 | 영향 구간과 순위 변화를 설명 가능 | 반경이 실제 위험 범위라는 뜻은 아님 |
| 시설 상태 직접 수정 | 확인된 고장 시설을 CCTV·조명 계산에서 제외 | 고장 상태를 직접 설명 | 시설 고유번호 연결·복구 검토가 선행되어야 함; 이번 미구현 |
| 통행 불가 구간 제외 | 확인된 폐쇄 도로 후보 제외 | 불통 구간 회피 | 도로 구간 식별과 신뢰할 근거 필요; 이번 미구현 |

반경 후보는 10·20·30m, 반영 강도 후보는 0.5·1·2입니다. 예를 들어 강도 1이면 제보 주변 40m를 지나는 길의 기존 비용에 40을 더합니다. 거리와 시설 선호가 섞인 기존 비교 비용의 단위에 맞춘 계산이며, 사고 확률·위험 점수·추가 소요시간이 아닙니다. 모두 비교 실험용 수치이고 현장·사용자 평가로 검증된 값은 아닙니다. 시설 인접 반경 50m와 제보 반경은 별개입니다.

## 구현 계약과 검사 기준 (실행 전 작성)

- 입력은 신뢰할 수 있는 서버 측 검토 결과입니다. 접수자의 자기 승인 입력은 받지 않습니다. 승인 담당자·근거·승인 시각·유효 시작/끝·좌표·유형이 필요합니다.
- 승인 완료, 아직 해결되지 않음, 승인 시각 이후이며 유효기간 안인 제보만 사용합니다. 종료 시각과 같으면 제외합니다. 강제 유효기간 기본값은 두지 않습니다.
- 이번 유형: 조명 고장, CCTV 고장, 보행로 장애물. 일반 불안감·긴급 신고·분류 미정은 제외합니다. CCTV 고장은 시설 점수와 별도로 인접 비용을 주는 후보이며 시설 좌표를 삭제하지 않습니다.
- 겹치는 제보 반경은 합집합 길이로 계산해 같은 구간을 중복 가산하지 않습니다. 중복 식별자는 오류로 처리합니다. 여러 제보를 반복 입력해 점수를 키우지 않습니다.
- 기존 후보의 거리·시설 비율·우회 한도와 원본을 보존합니다. 새 경로는 만들지 않고 기존 적격 후보 사이에서 다시 선택합니다. 빠른 길 선호는 시간 기준을 유지하며 제보 비용은 비교 정보로만 냅니다.
- 합성 미터 좌표에서 100m 직선의 중앙을 반경 10m로 둘러싸면 인접 길이 20m입니다. 기존 비용 100, 강도 2이면 새 비용 140입니다. 같은 점의 두 제보도 140이어야 합니다. 독립 후보 비용 130이면 추천이 바뀝니다. 끝·기간·보류·해결·먼 거리 제보는 비용 불변입니다.
- 잘못된 숫자·기간·좌표·식별자·빈 경로는 오류이며 0으로 대신하지 않습니다. 입력 순서로 동점 순위를 바꾸지 않습니다.
- 테스트는 합성 좌표와 대역 보행 API로 통합을 확인합니다. 실제 승인 제보, 현장 안전성, 운영 권한 검증을 뜻하지 않습니다.

## 다음 할 일

사람이 반영 범위·반경·강도를 결정하면 담당자가 승인 기록을 저장하는 인증된 관리 기능과 영구 저장소를 연결합니다. 현재 접수 메모리와 이 검토 결과는 자동 연결하지 않습니다. 공개 API에 승인 입력이나 새 점수 스위치를 노출하지 않습니다. 관리자 인증·영구 저장·공개 화면·실제 배포는 이번 범위 밖입니다. 현재 화면의 ‘경로 분석에는 반영되지 않음’ 안내는 유지합니다.

기본 경로 계산은 기존대로 사용할 수 있습니다. 선택 좌표 경로 계산의 서버 내부 선택 인수로 비교 모듈을 연결하고, 별도 명령으로 저장된 비교 입력을 재현합니다. 비교 입력에는 개인 위치가 있을 수 있으므로 공유·커밋하지 않습니다. 자동 검사 결과와 실행 명령은 아래에 추가합니다.

## 실행 방법과 합성 비교 결과

외부 API 없이 합성 입력을 재생합니다. 출력 파일은 새 경로여야 하며 소유자만 읽도록 생성합니다. 실제 개인 위치 입력·출력은 저장소에 올리지 않습니다.

```sh
.venv/bin/python scripts/compare_reviewed_reports.py --input experiments/datasets/reviewed_report_score_SYNTHETIC.json --output /tmp/reviewed-report-comparison.json --radius-m 10 --weight 2 --as-of 2026-11-20T07:45:00+09:00
```

`agent/data/selected_routes.py`의 `selected_compare`에서 서버 내부 선택 인수 `reviewed_reports`, `report_policy`, `report_as_of`를 함께 넘기면 같은 계산을 사용할 수 있습니다. 기존 웹 요청에는 이 인수를 추가하지 않았습니다. 기본 추천 필드는 보존하고 `report_comparison`에 별도 후보 추천·설정, 각 경로의 `report_effect`에 기존·추가 비용과 인접 길이·제보 식별자를 냅니다. 신뢰할 수 있는 검토 기록을 공급하는 것은 호출자의 책임입니다. 상태에 APPROVED를 적었다고 서버 인증이 되는 것은 아닙니다. 기준 시각은 명시적으로 전달하며 여행 시각에 유효한 제보를 비교하려면 해당 출발 시각을 넣어야 합니다.

합성 입력에서 경로 A의 기존 비용은 100, B는 130입니다. A만 중앙 제보 주변을 지나갑니다.

| 반경 | 강도 0.5의 A 비용/추천 | 강도 1의 A 비용/추천 | 강도 2의 A 비용/추천 |
|---|---|---|---|
| 10m | 110 / A | 120 / A | 140 / B |
| 20m | 120 / A | 140 / B | 180 / B |
| 30m | 130 / A(동점) | 160 / B | 220 / B |

반경·강도에 따른 순위 변화를 보여 주는 합성 계산이며 실제 선호·위험 측정이 아닙니다. [합성 9조건 원시 결과](../review/report_score_candidates_SYNTHETIC.json).

## 검증 범위

아래 검사는 모두 합성 자료로 수행했습니다. 실제 승인 제보나 운영 관리자 계정은 사용하지 않았습니다. 100m 손계산, 중복 구간, 만료·해결·미승인 제외, 잘못된 입력 거부, 우회 한도와 빠른 길 유지, 원본 보존, 로컬 명령과 서버 내부 연결을 자동 검사합니다. 공개 화면·저장소·인증 연결은 다음 단계입니다.

2026-11-20 07:44 KST 검사: 브라우저 제외 전체 360개 통과(기존 의존성 경고 1건), 이번 기능 검사 26개 포함. 로컬 합성 명령 실행 성공, 스테이징 8파일 공유 검사와 공백 검사 통과. 실제 API·모델 추가 호출 없음. 제출 브랜치에 직접 합치지 않고 별도 브랜치로 전달합니다.
