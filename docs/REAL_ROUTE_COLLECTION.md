# 실제 지도 경로 수집과 사용 범위

## 확보한 것

공개 연구 지점 두 구간에서 보행 프로필의 경로를 각각2개씩 받았습니다. 실제 지도 자료의 경로이며 합성 좌표로 만든 선이 아닙니다. 현장 보행·현재 공사·횡단 안전·점등 상태를 직접 확인한 것은 아닙니다.

| 연구 구간 | 기본 경로 | 경유 경로 |
|---|---|---|
| 서귀포 중앙로62번길 인근~시장 주변 대표점 |479.4m·약6.39분 |700.3m·약9.34분 |
| 삼무공원 대표점~누웨마루거리 공중화장실 지도점 |338.3m·약4.51분 |469.0m·약6.26분 |

두 번째 경로는 공개 가로등 원본의 위치 한 곳을 경유점으로 지정해 받은 조사 대안입니다. 서비스가 자동으로 제공한 동등한 대안이나 안전 추천이 아닙니다. 같은 출발·도착점인지 확인했고, 경로가 같은 것을 두 개로 세지 않았습니다.

시간은 제공 서비스의 추정치이며 실측이 아닙니다. 입력 지점은 보행망에 맞춰 서귀포 약4.6/5.1m, 연동 약24.3/10.4m 이동됐습니다. 원래 입력 지점부터 그 보행망까지의 접근이 보장되는 것은 아닙니다. 지명 검색 결과가 공원 대표점·공중화장실이므로 공원 입구나 거리 전체를 대표하는 지점으로 확정하지 않습니다.

## 출처·서비스 조건

- 데이터: © OpenStreetMap contributors, [ODbL1.0과 출처 표시](https://www.openstreetmap.org/copyright).
- 경로 제공: [FOSSGIS OSRM](https://routing.openstreetmap.de/about.html)의 routed-foot. 응답 단계가 모두walking인지 확인했습니다.
- 지도 오류 확인: https://www.openstreetmap.org/fixthemap .
- 공개 지점 검색에는 [Nominatim 사용 정책](https://operations.osmfoundation.org/policies/nominatim/)을 확인했습니다. 특정 공개 지점2건만 요청했고 초당1회 이하·식별 가능한User-Agent·응답 캐시를 적용했습니다. 실제 집이나 개인 위치는 보내지 않았고 일반 주소 검색 서비스로 앱에 탑재하지 않았습니다.
- 경로 요청은4건을 캐시했고 초당1회 제한을 지켰습니다. 서버가 요청 위치를 기록할 수 있으므로 개인 위치를 이 수집 절차에 넣지 않습니다.
- 원 데이터 시점·지도 그래프 버전은 응답에 없었습니다. 수집일을 지도의 최신 관측일로 바꾸지 않습니다. 서비스 전체 조건 페이지는 확인이 제한되어 공개 서비스 채택 전에 별도 확인해야 합니다.

## 코드와 사용 전 확인

`agent/data/foot_route_import.py`는 수집해 둔 응답을 오프라인으로 정리합니다. 온라인 호출 기능이 아니며 보행 모드·경로 좌표·양수 거리/시간·같은 끝점·중복 경로를 검사합니다.

현재 후보 메타데이터는 실제 자료임을 표시하되 서비스 사용 승인값은거짓으로 남겼습니다. `walkability_checked`는 제공자의 지도상 보행 모드 확인이고 `onsite_checked`는거짓입니다. 실제 서비스 채택·안전 판정·현장 검증 완료를 뜻하지 않습니다. 따라서 기존 파일 엔진의 실제 자료 사용 확인 게이트를 자동으로 통과시키지 않습니다.

원 응답·경로 후보 파일은 별도로 보관하며 이 저장소에는 포함하지 않았습니다. 가로등·CCTV를 자동 채택하거나 이 경로의 안전 점수를 계산하지 않았습니다. 설치 목적·좌표계·이용 조건을 확인한 자료와 실제 시연 구간을 정한 뒤 연결해야 합니다.
